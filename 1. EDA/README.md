# EDA - Exploratory Data Analysis

This folder contains the EDA notebook and data loading utilities for the MLOps churn prediction project.

## 🚀 Quick Start

### 1. Open the Notebook

```bash
jupyter notebook eda_example.ipynb
```

### 2. Configure Your Credentials

In the data loading cell, fill in your AWS configuration:

```python
REDSHIFT_CONFIG = {
    'host': 'your-cluster.af-south-1.redshift.amazonaws.com',  # TODO: Fill this
    'database': 'your_database',                                # TODO: Fill this
    'user': 'your_iam_user',                                    # TODO: Fill this
    'cluster_identifier': 'your-cluster',                       # TODO: Fill this
    'region': 'af-south-1',
    'iam': True,
    'iam_role': 'arn:aws:iam::123456789012:role/RedshiftS3Role',  # TODO: Fill this
    's3_export_path': 's3://your-bucket/tmp/eda_export',           # TODO: Fill this
    'cleanup_s3': False
}
```

### 3. Run the Analysis

The notebook will:
1. Load data from Redshift using UNLOAD (production pattern)
2. Perform data quality checks
3. Analyze features and correlations
4. Generate reproducible train/val/test splits

## 🔄 Production Alignment

The data loading process **exactly matches** the production pipeline:

```python
# extract_data_from_redshift/export_to_s3.py (Production)
UNLOAD ('SELECT * FROM table')
TO 's3://bucket/path/'
IAM_ROLE 'arn:aws:iam::account:role/RedshiftS3Role'
FORMAT AS PARQUET
ALLOWOVERWRITE
PARALLEL ON
MANIFEST
REGION 'af-south-1';
```

The same UNLOAD command is generated by `data_io.py` when you use `source='redshift'`.

## 🔐 Security

⚠️ **Important**: The notebook contains placeholder credentials that you must replace with your actual values.

**Best practices:**
- Never commit credentials to git
- Use IAM authentication (no passwords in code)
- Consider using environment variables or AWS Secrets Manager in production
- Temporary S3 exports can be auto-deleted with `cleanup_s3=True`

**For production-like testing:**
```python

    'host': 'your-cluster.af-south-1.redshift.amazonaws.com',
    'database': 'your_database',
    'user': 'your_user',
    'cluster_identifier': 'your-cluster',
    'region': 'af-south-1',
    'iam': True,
    'iam_role': 'arn:aws:iam::123456789012:role/RedshiftS3Role',

    source='redshift',

```

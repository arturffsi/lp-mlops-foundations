# Git quick guide

## Save changes to a new branch, go back to main, and pull latest

- `git stash`
- `git checkout -b my-new-branch` (pick any name)
- `git checkout main`
- `git pull`

## Go back to your branch and see your changes

- `git checkout my-new-branch`
- `git stash pop`

## How to list available branches

- `git branch`
